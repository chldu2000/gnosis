# 显示文本读控件树，屏幕文字才用 OCR

文本等于、文本包含和定位器的文本条件读控件树里的显示文本，包括屏幕外的节点。屏幕上看得见这段文字读像素，用 ONNX Runtime 加载 PP-OCR 中文模型。定位器只在控件树零匹配时才用屏幕文字再找一次。模型每一轮只看控件树和截图。控件树回答框架暴露了什么，像素回答人眼看见什么。标准控件上控件树更稳。

## Considered Options

- 所有文本都用 OCR：形近字和小字容易错，列表屏外的文字又会看不见。
- 所有文本都用控件树：自绘、图片和自定义组件上的字会消失，屏外文字会被当成看得见。
- 按来源分工：显示文本走控件树，屏幕文字走 OCR。

## Consequences

- OCR 的动态库和模型放在可执行文件旁边，发布物不只是一个 Go 程序。
- 同一段字可以让文本包含成立，同时让屏幕上看得见不成立。
