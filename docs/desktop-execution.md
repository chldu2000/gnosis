# 在 Windows 桌面端编辑和执行

构建 MyGo 原生桌面程序，并按 [Android 执行说明](android-execution.md) 启动 ADB 服务。将对应的安卓资源放在生成的程序旁边。

```powershell
go build -tags mygo_nowebview -ldflags '-H windowsgui' -o Gnosis.exe ./cmd/gnosis-desktop
.\Gnosis.exe
```

工作台左栏显示本窗口打开和新建的 YAML。切换文件会保留各自的编辑和选中的步骤。中间的列表用于选择步骤或套件引用，详情区用于填写字段。套件可以调整引用顺序或重复引用同一个用例。窗口较窄时，可通过「用例与套件」按钮打开文件列表。按 `Ctrl+S` 保存当前文件。

在右栏顶部的「准备执行」明确选定一台在线设备，然后点击「开始执行」。有未保存的编辑时会先提示保存并校验。执行期间可以切换文件继续编辑，右栏仍显示本次执行。暂停在安全点生效，已暂停的执行继续占用设备。右栏可以打开当前执行的用例，文件版本相符时可以定位到正在执行的步骤。

连接中断时，右栏标明上次同步的状态，已保存的报告仍可打开。重新打开窗口或恢复连接后，可查看最新进度。若显示「启动待确认」，点击「核对启动」查找原请求。仍暂无匹配时，右栏顶部会显示「准备新执行」。再次发起前可确认本次所用的文件和设备。

执行结束后，右栏顶部回到「准备执行」，最近一次执行的结果和「打开会话报告」入口在下方。单用例结束并保存报告后，桌面端会打开系统浏览器。报告可以按用例名称、文件路径、序号和结果查找，并在步骤旁查看截图与 AI 轨迹。会话文件夹位于 `%LOCALAPPDATA%\gnosis\reports`，将 `report.html` 和相邻的 `attachments/` 一起移动即可离线查看。

需要执行 AI 步骤时，在「模型设置」填写完整的 Chat Completions URL、模型名称和 API 密钥。模型地址和名称保存在当前 Windows 用户的宿主设置中，密钥保存在 Windows 凭据管理器。修改从下一次执行生效。

连续暂停的默认时限为 30 分钟。可在启动桌面端前用 `GNOSIS_PAUSE_LIMIT` 设置独立执行进程的暂停时限，例如 `10m`。命令行用法见 [CLI 执行说明](cli-execution.md)。

## 在设备界面上选元素

拖动选择器右下角可调节宽度和高度，也可以用「最大化」和「还原」切换。截图随弹窗等比缩放。在同一工作台窗口再次选取元素或复核离线截图时，会沿用上次的尺寸。

打开或新建用例，在右栏选定在线 Android 设备，点击编辑区的「从设备选元素」。在手机上导航，然后点「刷新界面」。点截图可选中该处最深的节点；从树中选择父节点或子节点可查看它在截图中的边界。搜索框支持 ID、文本、描述和类型。每个候选定位器旁的数字是本次树中的匹配数。列表中出现重复 ID 时，可结合文本选到目标行。

「新增点击」和「新增断言」将步骤追加到用例。「填入当前步骤」可为现有点击、长按或支持定位器的断言更换目标，保留已填的预期值。例如要验证通知开关已开启，在表单里选择 `attr_equals`、属性 `checked`、期望值 `true`，再选取开关填入该步骤。选择只修改草稿，可以在设备开关仍关闭时完成编辑。运行中或已暂停的执行释放设备后即可重新采集。

## 在工作台复核 AI 草稿

在右栏顶部执行含 AI 步骤和预期断言的单用例。通过后点结果区的「复核用例草稿」，在新打开的文档中逐步核对原目标、动作参数和说明。「查看动作后截图与断言」可核对实际到达的界面。对标出的坐标点击，点「复核坐标 · 查看动作前界面」，从当时的树或截图选定目标，再点「填入当前步骤」改成定位器点击。此过程可在设备离线时完成。

首次保存时选择新文件名。随后可从右栏顶部独立重跑，或按普通 YAML 加入套件。复核材料在对应会话的 `case-draft.json` 和 `attachments/` 中，复制整个会话目录可保留关联。每次已开始的执行都有一个 `report.html`。
