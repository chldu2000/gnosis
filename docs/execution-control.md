# 执行控制与云端调度

第五阶段交付本机启动、暂停、恢复、取消和进度查看。云端调度在本机执行控制验收后接入，远程提供同样五项能力。完整 HTML 报告和截图保存在执行主机，远程进度只传递状态、当前位置、已确定的结果和可公开诊断。

## 本仓库与云端项目的职责

- Gnosis 仓库实现共享 Go 核心、本机执行进程、MyGo 桌面端接入，以及后续的实例端连接、设备上报、用例包校验和命令处理。
- 独立云端项目实现实例登记和授权、操作者界面、任务排队与调度、租约签发和续约、用例包分发、进度存储及操作记录。双方依照本页约定对接，并共同维护兼容的协议。
- 云端首版面向一个组织和多台 Windows 主机，每台主机登记一个 Gnosis 实例，每个实例同时最多执行一个任务。任务可分派到多个实例并行执行，每个任务对应的用例或套件始终在一台设备上执行。

## 本机执行控制

### 桌面端与执行进程

MyGo `mygo_nowebview` 桌面端直接使用共享 Go 库编辑和校验本机文件，通过仅向授权本机用户开放的 Windows 命名管道请求执行。桌面端优先连接当前 Windows 用户已有的执行进程，并在需要时启动。执行进程独立于窗口生命周期。关闭窗口后执行照常进行，重开窗口后重新查询状态和订阅进度。桌面端通过系统浏览器打开本机 HTML 报告。CLI 保留现有调用方式，复用相同的 Go 执行逻辑和设备占用规则。

执行进程提供设备列表和可用状态。桌面端刷新列表，显示平台和设备标识，并要求操作者明确选定设备。选定的设备离线时，界面显示该设备不可用，由操作者重新选择设备。

桌面模型地址和名称保存在当前 Windows 用户的宿主设置中，密钥保存在 Windows 系统凭据存储中。执行进程在启动一次用例或套件时读取一份模型设置，后续修改从下一次执行生效。CLI 继续支持现有的环境变量和单次运行覆盖。

重开窗口时优先显示仍在进行的执行，否则恢复最近一次执行的状态和已保存的报告链接。本机保留最近一次执行的快照供窗口恢复。各次执行的 HTML 报告按原有规则保存。

在执行、暂停和清理期间，执行进程独立运行。没有桌面窗口连接且进程空闲时，执行进程在保存最近一次执行状态后退出。

确认执行进程异常退出后，桌面端将该进程尚未结束的执行显示为「执行中断」，保留已保存的用例结果和报告链接。操作者可以发起新的执行。

| 操作 | 约定 |
| --- | --- |
| `Start` | 提交带请求 ID 的启动请求，指定用例或套件及明确选定的设备。接受后返回执行 ID。进程或设备已占用时，本机启动请求直接返回占用诊断。 |
| `Get` | 返回当前状态、位置、已确定的结果及最新事件序号。 |
| `Watch` | 从指定事件序号后订阅进度。重连先取最新快照，再从快照序号接续。历史事件已过期时，以快照恢复显示。 |
| `Control` | 对指定执行请求暂停、恢复或取消。返回当前状态，实际生效通过状态和事件确认。 |

启动请求未收到确认时，桌面端重连后先按请求 ID 查询。确认已接受时，回到该次执行。仍无法核实时，显示「启动待确认」，由操作者决定是否发起新的执行。

执行 ID 标识一次用例或套件的整个控制过程。套件的进度和命令作用于整个套件，每条用例独立记录结果。获授权的本机操作者也能控制云端派来的执行。桌面和云端的启动请求共用进程和设备占用，先取得占用的一方继续。暂停和清理期间仍持有占用。

### 暂停与恢复

- 收到暂停请求先显示「正在暂停」，到安全点后显示「已暂停」。在用例之间、步骤之间、断言轮询之间和 AI 轮次之间检查暂停。已发出的设备动作先收尾，再确认暂停。
- `wait` 和断言在暂停期间冻结剩余时长。恢复后的断言先重新观察设备，并继续使用剩余时限。AI 下一轮也重新观察设备。
- 连续暂停默认最多 **30 分钟**，由部署配置调整，使用实际经过时间计时。达到上限时按取消流程收尾。云端执行在暂停期间继续续约。

### 取消、结果和报告

- 核心用一次执行的取消信号贯穿等待、断言轮询、模型请求和设备 I/O。执行进程决定命令何时生效，并串行确认控制命令和终态。客户端关闭连接只停止订阅，执行的取消由明确命令、时限或租约到期触发。
- 取消生效后停止安排新的用例、步骤和设备动作。已经发出的操作可能已在设备上生效，无法确认时在记录中注明。已确定的用例结果保留，取消时尚未形成的用例结果保持空缺。正常终态先确定时，随后到达的取消返回该终态。
- 已开始的用例保存已有步骤、轨迹和截图，报告注明执行状态。未开始的用例没有结果或报告。未派发的排队任务取消后只保留任务记录。
- 取消或租约到期时，仍为输入法恢复、报告收尾和释放设备留出独立的限时清理过程。Android 输入法恢复失败只记入注明。进程异常退出时，云端不能据此推定清理已经完成。

## 云端接入约定

### 派发与用例包

操作者在已授权的实例与设备列表中明确选择「Gnosis 实例 + 设备」并提交一个用例或套件。同一用例需要在多台设备执行时，分别创建任务。选中的设备忙或离线时，任务等待原设备，默认最多 **30 分钟**，由部署配置调整。排队到期显示「已过期」。

任务绑定固定版本的用例包及其摘要。实例下载并验证摘要，在独立的包目录中完整载入用例或套件后才开始执行。套件引用按现有顺序载入并保留重复项，解析后的路径须留在包内。本机用例和套件继续沿用现有文件格式及载入规则。模型地址、模型名和密钥由执行主机的设置提供。

### 租约与断线

- 云端签发的执行租约绑定任务、执行尝试、实例和设备。默认有效期 **60 秒**，实例默认每 **15 秒**续约，两个数值均可配置。暂停期间照常续约。实例使用保守的本地截止时间约束设备动作，续约失败到期后停止安排新动作并收尾。
- 网络短暂中断时，执行可在有效租约内继续，实例重连后补报状态与可用进度。同一执行尝试的租约到期后收尾，后续重连用于补报结果。继续执行须由操作者另起任务。
- 实例离线时，云端持久保存取消请求并显示「取消待确认」。实例确认实际取消后才显示「已取消」。如果执行已经正常结束，保留该终态。暂停和恢复仅在实例在线时发送，过期命令在重连后失效。
- 云端已下发且无法确认是否开始或结束的尝试显示「中断待确认」。实例重启后可以补报能够关联到该尝试的本地持久化终态。无法确认先前操作的影响时，由操作者决定是否创建新任务。

### 标识、进度和权限

- 任务 ID 标识提交的请求，执行尝试 ID 标识一次派发，命令 ID 用于控制命令去重，租约代次用于拒绝旧租约及其控制命令。进度事件按执行尝试和序号去重。相同控制命令重发时返回该命令的既有确认或执行终态。
- 云端进度包含任务状态、当前用例和步骤、已确定的用例结果及可公开诊断。连接恢复时先同步快照，再补报仍可取得的进度。报告、截图和模型凭据留在执行主机。
- 云端接入默认关闭，由主机显式启用。管理员登记或撤销实例并授予权限。操作者只能在获授权的实例上提交任务、查看进度和发送控制命令。登记完成后，获授权任务可以无人值守启动。
- Go 实例使用带独立 mTLS 身份的 Protobuf/gRPC 双向流，主动连接云端。独立云端项目采用 Go，使用 PostgreSQL 保存任务、租约和操作记录，使用对象存储提供固定版本的用例包。

## 验收场景

1. 用设备替身让 `wait`、断言轮询和 AI 步骤分别遇到暂停或取消。确认恢复保留剩余时长，暂停期间其他执行拿不到设备。
2. 取消执行到第二条用例的套件。确认第一条的结果与报告可读，第二条有部分报告，后续用例没有开始，清理完成后设备可以再次占用。
3. MyGo 发起执行后关闭并重开窗口。确认执行进程继续工作，界面恢复当前状态，可继续控制同一次执行。用本机和云端同时请求占用同一设备验证互斥。
4. 使用可控时钟和云端替身验证排队到期、暂停到期、短暂断网、租约到期、离线取消、重复命令和重启补报。确认已下发但状态不明的任务会等待核对。
5. 用无效引用、越出包目录的引用和摘要不匹配的包验证启动前拒绝。确认实例仅传出约定的进度字段，权限判断和报告存放范围符合约定。
