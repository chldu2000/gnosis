# 04: 载入套件

**What to build:** 测试编写者用一份套件文件按顺序引用用例。载入套件时每条引用都已读完并检查过。有一条失败，整份套件被拒绝，并指出第几条引用和用例文件里的位置。

**Blocked by:** 03: 载入断言和 AI 步骤

**Status:** ready-for-agent

套件文件只允许一个键 `cases`，值是非空的字符串序列。每一项是相对于套件文件所在目录的路径，允许 `..`。绝对路径、空字符串、空序列都拒绝。套件没有名称。同一路径出现两次时，结果里是两份独立的用例。

引用读不到，或该用例载入失败时，不返回部分套件。拒绝信息包含套件文件、这是第几条引用（从 1 起）、用例文件，以及用例内部的行和列（读不到文件时，位置指套件里的那一行）。

带 `cases` 的文件是套件。只有 `name` 或 `steps` 的文件仍是用例。两种键同时出现则拒绝。

- [ ] 套件按相对路径依次载入用例，顺序与文件一致
- [ ] 同一用例引用两次得到两份用例
- [ ] 空套件、绝对路径、不认识的字段被拒绝
- [ ] 某条引用读不到或用例有错时，整份套件被拒绝，并带有引用序号和用例位置
- [ ] 套件文件和被引用的用例文件都不会被修改
