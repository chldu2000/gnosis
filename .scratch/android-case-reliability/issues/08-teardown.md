# 08 主步骤结束后显式清理测试状态

Status: ready-for-agent

[所属规格](../spec.md)

用例改了通知开关后断言失败，套件的下一个用例继承了污染状态。

## 实现与边界

增加用例级有序清理动作，在设备仍归本次执行占用时运行，清理诊断与主结果分别保存。主流程失败、阻塞或错误均保留原结果；清理失败标记套件环境不可继续，停止后续用例并让 CLI 返回非零。用户取消、租约终止和设备离线停止安排新动作，记录未完成清理；沿用输入法恢复及释放顺序。

## MyGo 桌面交互

编辑器给步骤列表增加独立「清理步骤」分组，右栏与报告分开展示主流程和清理结论。

## 验收条件

- [ ] 主流程失败且清理成功时，下一条用例看到恢复后的状态。
- [ ] 主流程通过但清理失败，以及主流程失败且清理失败，都可读取两项结论；后续用例保持未开始。
- [ ] 取消、断线及输入法恢复异常不会造成重复清理或覆盖已有结论。
