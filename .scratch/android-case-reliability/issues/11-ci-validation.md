# 11 离线校验用例并向 CI 输出可区分的结果

Status: ready-for-agent

[所属规格](../spec.md)

只有动作的用例也可能让 CI 成功，维护者需要知道一次合并实际验证了什么。

## 实现与边界

CLI 增加离线 validate 入口，支持明确要求每条用例有预期断言；共享加载与校验规则。执行可选写版本化 JSON 摘要，包含执行状态、用例次序、结果、未开始条目、诊断和报告路径。保留普通执行的退出码与标准输出路径约定；校验错误返回非零且不产生执行报告。

## MyGo 桌面交互

在「文件操作」提供「校验」；对编辑中的草稿显示校验对象，给出文件和步骤位置。「缺少预期断言」在普通模式仅提示，CI 门槛由调用方显式选择。

## 验收条件

- [ ] 无设备、无模型可校验套件全部引用；含零预期断言的用例在严格模式被指出。
- [ ] 检查重复引用、已执行、失败、阻塞、错误、取消和未开始的 JSON 表达；HTML 与 JSON 的序号、结果一致。
- [ ] 有未保存修改时文件内容和执行状态不因校验改变。
