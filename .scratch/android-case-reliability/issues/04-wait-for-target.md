# 04 点击前等待目标就绪且只下发一次动作

Status: ready-for-agent

[所属规格](../spec.md)

界面切换时元素可能晚到；复制多条等待步骤既慢也会造成偶发错误。

## 实现与边界

给定位器点击、长按增加可选正时限；省略仍立即定位。启用后轮询到唯一且有可用边界的目标；暂时零个或多个继续观察，设备读取错误立即结束。沿用暂停计时与取消检查点，动作一经下发即结束等待，未收到回执也不再次下发。

## MyGo 桌面交互

在动作详情的「等待目标」填时限；右栏可见等待哪个步骤，报告区分等待用尽和动作下发后出错。

## 验收条件

- [ ] 模拟三个时刻从无目标到重复再到唯一，仅收到一次点击。
- [ ] 暂停不消耗时限，取消等待产生零次点击；下发后返回错误仍只有一次点击。
- [ ] 旧 YAML 保留即时错误；桌面保存、重开和 CLI 执行得到一致行为。
