# 01 报告显示断言的最后一次观测

Status: ready-for-agent

[所属规格](../spec.md)

同一条购物车数量断言失败时，作者要区分没找到购物车、找到两处以及数值不符。

## 实现与边界

在一次断言判定中保留定位条件、实际来源、索引前候选数、索引后候选数、比较值与时限。绝对定位、参照缺失、属性缺失、读取错误分别编码。仅保留最后一轮、至多三个有序候选的必要字段，注明截断；普通文本值作为受限诊断字段处理，复用现有密钥清除规则，敏感参数接入见 12。派生 HTML 和本机进度摘要均使用这份观测，历史记录允许缺字段。

## MyGo 桌面交互

右栏结果显示一句原因。打开系统浏览器的报告可展开该步骤，对照期望、实际与已有截图。「查看断言步骤」沿用文件版本核对；版本不同仍可读当时的报告。

## 验收条件

- [ ] 同一 YAML 配三个设备观察序列，报告分别给出零候选、多候选且均不满足、唯一候选实际为 2 而期望为 3。
- [ ] 预期断言不成立为失败，前置断言不成立为阻塞，控件树读取失败为错误；断线重连后摘要一致。
- [ ] 检查旧记录、长候选列表及 HTML 特殊字符，报告可离线阅读，轮询次数增加不会增加截图数量。
