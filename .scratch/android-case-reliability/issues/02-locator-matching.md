# 02 动态文本和屏幕范围可用作定位条件

Status: ready-for-agent

[所属规格](../spec.md)

商品数量变化或列表预加载时，作者仍要稳定点到屏幕中的那一行。

## 实现与边界

增加显示文本和描述的字面子串条件，同一字段的精确和子串模式互斥。屏内过滤取非零边界与屏幕的交集；索引在参照范围和所有过滤之后应用。启用屏内条件时点击交集中心。仅普通纯显示文本定位器可在树零匹配时做本机屏幕文字后备；精确模式保持整行相等，子串模式返回文字区域，不能声称得到词级点击位置。

## MyGo 桌面交互

在现有元素选择器给文本字段加「等于／包含」和「仅屏幕内」。改条件立即在同一次采集上更新计数与高亮。屏幕文字候选标示区域和来源；只有树材料的离线预览明确显示后备尚未验证。

## 验收条件

- [ ] 购物车(3) 改为购物车(4)仍可命中；描述条件不会触发屏幕文字后备。
- [ ] 同名屏外节点、部分露出的节点及零面积节点产生正确计数；旧用例仍精确匹配。
- [ ] 验证参照、索引、两行屏幕文字均匹配和被浮层覆盖的情形；界面只承诺几何上的屏内。
