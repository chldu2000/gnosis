# 07 显式冷启动、停止应用和打开深链

Status: ready-for-agent

[所属规格](../spec.md)

同一应用从后台恢复和从冷启动进入的界面不同，作者需要声明起点。

## 实现与边界

在封闭设备操作中提供停止应用、普通启动、冷启动、按 URI 打开指定应用。普通启动沿用已有入口；冷启动先停止再启动，保留应用数据。URI 与显式入口互斥，交给目标应用处理；无可用处理入口时报错。按参数传递并审查报告中的 URI 查询值。

## MyGo 桌面交互

「打开应用」显式选择启动方式，相应显示入口或 URI；「停止应用」独立列入步骤菜单。编辑和选取目标不执行设备操作。

## 验收条件

- [ ] 预置后台状态，普通启动与冷启动呈现预期区别；验证数据仍在。
- [ ] 覆盖无处理入口、非法 URI、应用标识错误和未支持平台；单纯打开用例不会启动或停止应用。
