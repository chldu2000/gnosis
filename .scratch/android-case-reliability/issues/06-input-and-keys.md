# 06 区分按键、输入法提交和追加输入

Status: ready-for-agent

[所属规格](../spec.md)

搜索流程需要提交输入法动作；已有文字时，作者也要能选择替换或在光标处追加。

## 实现与边界

保留 type 默认替换；显式追加沿用当前焦点。分别映射物理 Enter、输入法 Search、退格、Tab、最近任务；由设备适配报告可用能力。先用固定 ASCII 与中文验证首选路径；替代输入只在明确可用且可证明保持焦点、字符与替换/追加语义时开放。在结果不明时不改走另一条路径重输。

## MyGo 桌面交互

按键区区分「回车」与「提交搜索」；文本字段加「替换／追加」。失败说明分别提示没有可识别焦点、输入法安装被拒、设备不支持该动作；保留已有输入法恢复说明。

## 验收条件

- [ ] 同一搜索框验证 Enter 和 Search 实际触发的行为；覆盖退格、焦点切换及最近任务。
- [ ] 非空字段验证替换和光标中间追加，中文和空字符串分别验证；焦点未知、安全输入不可用时给出可执行诊断。
- [ ] 平台未验证的按键须在能力表注明；旧 YAML 和旧 AI 动作仍可重跑。
