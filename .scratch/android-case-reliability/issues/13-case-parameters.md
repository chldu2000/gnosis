# 13 为同一用例绑定多组静态测试数据

Status: ready-for-agent

Blocked by: [12](12-sensitive-data.md)

[所属规格](../spec.md)

作者希望同一搜索用例换关键词、同一登录用例换账号，同时保护凭据。

## 实现与边界

声明必需的命名参数，首批允许整字段绑定至类型兼容的动作或断言值。运行时选择命名数据行，敏感参数通过执行环境引用取值。用例、套件展开和严格校验检查名称、缺项与类型；启动之前固定本次绑定。报告保留数据行标识和非敏感摘要，敏感绑定要求相应保护策略。

## MyGo 桌面交互

字段菜单允许在「固定值／参数」之间切换。准备执行时选数据行，缺项跳转到参数；密值遮盖，保存文件不会写入解析后的值。

## 验收条件

- [ ] 相同 YAML 两次绑定不同数据得到不同的预期断言；报告能区分执行。
- [ ] 缺失参数、未知参数、类型不符在设备操作之前暴露；套件重复执行和草稿另存为不会把凭据写回。
