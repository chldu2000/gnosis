# 01 从本次单用例执行生成并另存草稿

Status: resolved

Blocked by: 无

[所属规格](../spec.md)

通过 CLI 交付一个完整的生成、复核和显式保存入口。

## 验收条件

- [x] 含多个 AI 步骤的混合用例生成可加载的 YAML，动作参数、前置断言及预期断言的次序可核对。
- [x] 来源文件在执行期间修改时，草稿仍对应起始版本；另存保留来源文件及其编辑。
- [x] 覆盖资格边界并说明原因，坐标点击可辨认，拒绝生成时没有新用例文件。

## Comments

公开 CLI 回归覆盖两个 AI 步骤之间的前置断言、末尾的预期断言、试跑过程中修改源文件、拒绝覆盖已有文件，以及不具备生成资格的执行。见 [CLI 草稿测试](../../../cmd/gnosis/authoring_test.go)。
