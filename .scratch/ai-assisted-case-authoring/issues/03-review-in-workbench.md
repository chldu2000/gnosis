# 03 在工作台复核、另存并重跑

Status: resolved

Blocked by: [02](02-verify-android-rerun.md)

[所属规格](../spec.md)

在现有编辑器中呈现草稿并对接本机执行进程。

## 验收条件

- [x] 对照目标、动作、截图与原断言复核路径，坐标点击提示可见。
- [x] 试跑与重跑入口在右栏顶部，明确另存后 CLI 也能执行该文件，报告仍可查看。

## Comments

真机试跑后，用 Windows 工作台交互测试打开草稿，核对动作后截图与原预期、在动作前界面改选定位器。另存的同一文件分别由 CLI 和工作台的独立执行进程重跑通过。见[工作台使用说明](../../../docs/desktop-execution.md)。
