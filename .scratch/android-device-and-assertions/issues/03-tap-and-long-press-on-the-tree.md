# 03: 按控件树点击和长按

**What to build:** 点击和长按在控件树里找到恰好一个元素，再点它的中心。一个都没有，或找到多个又没写第 n 个，这一步就是错误，手势不会发出。本票还不使用屏幕文字。

**Blocked by:** 01: 开始或拒绝一次执行

**Status:** resolved

定位器的资源 id、显示文本、描述、类型都按字面精确匹配，不裁剪空白。先用这些条件过滤控件树，树的顺序就是匹配顺序。第 n 个从过滤结果里取，从 1 起。控件树节点包括当前不在屏幕内的元素。

点击和长按要求恰好一个元素。零匹配、多个匹配又没写第 n 个、或第 n 个超出个数，都是错误，手势不发送。命中时，点击和长按落在该元素范围的中心，像素四舍五入到整数。长按时长用载入结果。做完的结论是已执行，并带结束截图。

控件树已经有匹配时，不读取屏幕文字。定位器里有资源 id、描述或类型，且控件树零匹配时，也就是没找到，不读取屏幕文字。只有显示文本的定位器在本票里同样只查控件树；屏幕文字后备留给后面的工单。

- [x] 第 n 个从 1 起；点在命中范围的中心；长按时长使用载入结果
- [x] 屏幕外的节点仍可被命中
- [x] 零匹配、未写第 n 个时的多个匹配、第 n 个超出个数，都是错误，手势不发送
- [x] 控件树已有匹配，或定位器含资源 id、描述或类型且树为零匹配时，不读取屏幕文字
- [x] 做完的结论是已执行，并带结束截图
