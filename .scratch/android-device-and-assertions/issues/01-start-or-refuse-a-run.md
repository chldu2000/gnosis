# 01: 开始或拒绝一次执行

**What to build:** 发起执行的人把一条已经载入的用例交给执行入口和一台设备。设备不在线、已被占用，或这个进程里已有执行时，这次不开始，也没有执行记录。空用例开始后的结果是已执行。等待按载入时长停住，不向设备发送手势，并留下结束时的截图。uiautomator2 没有就装上，结束时不卸载。输入法若被这次执行切换过，在结果确定后切回。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

执行入口接受一条已经载入的用例、一台设备和一个时钟。载入入口不变，执行不解析文件，也不补默认值。

没开始的情况只有三种：设备不在线、设备已被占用、这个进程里已有一次执行尚未返回。没开始就没有执行记录，不去占用设备，也不动输入法。

开始的顺序是：先判断能不能开始；能开始就记下开始时间并占住进程和设备；然后确保 uiautomator2 已安装；再执行步骤；结果确定后，若这次执行切换过输入法就切回；最后释放设备。安装失败发生在已经开始之后，结果是错误，步骤结论为空。已经安装则不重装。设备接口没有卸载。

空用例的结果是已执行，没有步骤结论。等待只推进时钟，时长用载入结果，时长为 0 时立即结束；结论是已执行，并带结束截图。步骤有名称时写入结论，没写则名称是空的。截图失败时该步是错误，用例结果是错误。

执行记录包含用例名称、设备标识、开始时间、结果、按顺序的步骤结论，以及可选的输入法注明。每条步骤结论包含名称、结论和结束截图。记录里没有模型名、模型地址和密钥。输入法切回发生在释放之前；切不回去只加注明，不改变结果。

执行不修改用例文件，开始前不清理应用，也不回到主页。返回前释放自己占用的设备。没开始的调用不释放别人的占用。

- [ ] 设备不在线、设备已被占用、进程内已有执行，都不开始，没有执行记录，也不动输入法
- [ ] 空用例的结果是已执行，记录里有用例名称、设备标识和开始时间，没有步骤结论，也没有模型名、模型地址和密钥
- [ ] 等待使用载入时长，时长为 0 时立即结束；期间不向设备发送手势；结论是已执行，并带结束截图
- [ ] 步骤名称与载入结果一致，没写名称时结论里的名称是空的
- [ ] 尚未安装 uiautomator2 时会安装；已经安装则不重装；结束时不卸载
- [ ] 安装失败时结果是错误，没有任何步骤结论
- [ ] 结束截图失败时，该步是错误，用例结果是错误
- [ ] 输入法被这次执行切换过时，在结果确定后、释放前切回；切不回只增加注明，结果不变
- [ ] 执行不修改用例文件，开始前不清理应用、不回到主页
