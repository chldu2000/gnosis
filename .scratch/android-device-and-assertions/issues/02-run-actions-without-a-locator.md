# 02: 执行启动、按比例点击、滑动、输入和按键

**What to build:** 同一执行入口能做完不靠定位器的动作。启动应用、按比例点击、滑动、输入文本和按键按载入顺序发生，做完的结论是已执行。比例越界或屏幕尺寸读不到时，手势不发到设备上，这一步是错误。操作失败或中途断开时用例停下，后面的步骤没有结论。

**Blocked by:** 01: 开始或拒绝一次执行

**Status:** resolved

在 01 的步骤上增加这些动作。动作不轮询，不做重试。每个作出结论的步骤都有结束截图。参数一律用载入结果，不再补默认值。

- 启动应用：使用应用标识。入口为空时用应用自己的入口，写了则打开该入口。启动失败则该步是错误，用例停下。
- 按比例点击：把宽高比例换成像素再点。比例 0 对应像素 0，比例 1 对应该边长度减 1，中间线性换算后四舍五入到整数。闭区间 0 到 1 都合法。
- 滑动：起点和终点同样换算。时长用载入结果。任一比例越界时整步是错误，滑动不发送。
- 任一比例在 0 到 1 之外，或屏幕宽高读不出来时，该步是错误，对应手势不发送。
- 输入文本只替换当前焦点里的全部文字。执行入口在输入前不点击。没有焦点或输入失败时，该步是错误。
- 按键只接受返回或主页。

设备操作失败，或执行途中设备断开，当前步是错误，用例结果是错误，停止。还没执行的步骤不出现在结论里。

- [x] 启动、按比例点击、滑动、输入和按键按载入顺序做完，结论都是已执行，发给设备的参数与载入结果一致
- [x] 启动没写入口时用应用自己的入口；写了则打开该入口；启动失败则该步是错误并停下
- [x] 比例 0 和 1 会换成像素并发出；任一比例越界，或屏幕尺寸读不到时，不发手势，该步是错误
- [x] 滑动时长使用载入结果；输入之前不点击；输入失败是错误
- [x] 按键可以是返回或主页
- [x] 设备操作失败或执行途中断开时，当前步是错误，用例停下，后面的步骤没有结论，也不重试
- [x] 每个作出结论的步骤都有结束截图
- [x] 执行不修改用例文件
