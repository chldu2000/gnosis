# 01 在工作台刷新界面并双向选取元素

Status: resolved

Blocked by: 无

[所属规格](../spec.md)

从新用例连接可用设备，在截图和控件树间复核选区。

## 验收条件

- [x] 采集包含截图、屏幕尺寸、节点层级和元素边界；手动刷新后选区对应当前采集。
- [x] 点截图与选树节点双向高亮，重叠时能从树区分父子节点。
- [x] 离线或占用时反馈原因，点选开关不改变设备状态，整个流程无需模型。

## Comments

工作台通过本机执行进程采集真机界面。选择通知开关并新增点击步骤后，再次采集仍为关闭；窗口交互测试验证从截图选中重叠区域的子节点、从树改选另一个节点。接口测试覆盖离线、运行中与暂停中的设备占用。见[选择器测试](../../../cmd/gnosis-desktop/picker_windows_test.go)与[占用测试](../../../internal/localrun/capture_windows_test.go)。
