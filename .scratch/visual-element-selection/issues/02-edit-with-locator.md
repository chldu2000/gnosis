# 02 用候选定位器编写或修订步骤

Status: resolved

Blocked by: [01](01-pick-live-element.md)

[所属规格](../spec.md)

通过选取元素完善当前用例，并保存为既有格式。

## 验收条件

- [x] 显示候选条件和匹配数，重复资源 ID 能反映多个匹配。
- [x] 可填入已有步骤、新建动作或断言，作者可指定不同于当前状态的预期值。
- [x] 保存并重新载入，定位器、预期值与普通编辑器一致。

## Comments

工作台测试验证同一个开关 ID 匹配两项，加入文本可缩小至一项。为原断言换定位器后保存并重载，保留作者设定的 checked=true；真机场景另外验证新增点击与新增断言。见[选择器测试](../../../cmd/gnosis-desktop/picker_windows_test.go)。
