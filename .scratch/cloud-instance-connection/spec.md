# Gnosis 实例接入云端调度

## Problem Statement

操作者需要在获授权的远程设备上发起并控制执行。连接中断后，已经对设备生效的动作可能无法重做，操作者需要能核对这一次执行尝试的状态。

## Solution

由显式启用的 Windows 实例主动连接云端，上报设备，在有效租约下校验并执行固定版本的用例包，接受控制并回传可公开的进度。

## User Stories

1. 作为管理员，我想显式启用连接并识别每个实例，以便管理组织中的执行主机。
2. 作为操作者，我想选择获授权的实例和设备，以便任务准确发往指定设备。
3. 作为操作者，我想知道设备忙或离线，以便让云端等待原设备或按配置过期。
4. 作为操作者，我想任务绑定用例包的固定版本和摘要，以便获知实际执行的内容。
5. 作为编写者，我想套件开始前校验全部引用并保留重复引用，以便云端与本机执行一致。
6. 作为本机用户，我想远程执行遵守已有设备占用，以便同一设备不会同时响应两次执行。
7. 作为操作者，我想查看当前用例、步骤和已确定结果，以便跟踪套件进度。
8. 作为操作者，我想暂停、恢复或取消一次尝试，以便控制后续动作。
9. 作为操作者，我想重复命令得到相同确认，以便重连后可以安全核对结果。
10. 作为管理员，我想实例只在本次租约内安排设备动作，以便租约到期时收尾并释放设备。
11. 作为操作者，我想短暂断线后看到当前状态和可补报的进度，以便衔接断线前的记录。
12. 作为操作者，我想知道离线取消是否已生效，以便区分待确认和已取消。
13. 作为操作者，我想在重启后核对已有终态，状态不明时自行决定是否另起任务，以免重复手势或输入。
14. 作为执行主机管理员，我想报告、截图和模型凭据留在本机，以便掌握这些信息的访问范围。

## Implementation Decisions

- 实例以独立 mTLS 身份主动建立 Protobuf/gRPC 双向流。云端接入默认关闭。组织权限、排队和调度归云端项目，首批每台 Windows 主机一个实例，每实例同时至多一项任务。
- 任务指定实例、设备、包版本及摘要。在独立包目录中完整校验后启动，解析后的引用须在包内。实例使用主机模型配置和已有共享执行器。
- 区分任务、尝试、命令、租约代次和进度序号。租约绑定尝试、任务、实例和设备。按可配置的 60 秒有效期、15 秒续约间隔运行，暂停期间仍续约。
- 实例按保守的本地截止时间约束动作。断线期间租约仍有效可继续，到期停止安排新动作并收尾。恢复连接先同步快照，再补报可用事件。旧代次或过期控制命令失效。
- 离线取消由云端保存，重连核对实际终态。实例重启后补报可关联的持久化终态，状态不明的尝试等待人工核对。远端只接收约定的进度及可公开诊断。

## Testing Decisions

- 以可控云端替身连接实际实例作为主入口，使用可控时钟、测试包与设备替身。沿用本机执行进程测试中的竞争启动、进度读取、重连及重启场景，观察协议确认、设备动作与本机报告。
- 分别模拟包摘要不符、引用越界、同设备竞争、重复命令、旧租约、暂停时到期、短暂断线、离线取消及重启；核对设备动作次数和释放时机。
- 跨项目联调核对授权、撤销及原设备排队到期（默认 30 分钟）的可见结果。独立云端未就绪时，替身验证实例侧协议行为。

## Out of Scope

云端调度器、操作者界面、租约签发、任务存储、对象存储及组织授权管理由独立项目交付。
