# 02 执行模型动作并记录轨迹

**What to build:** 模型可在每轮请求一次按比例点击。执行器使用已有动作路径完成操作，并把动作后的截图和模型说明写入轨迹。模型看到新界面后可以继续或停手，执行器也会在达到用例给定的上限时结束该步。

**Blocked by:** 01 开始 AI 步骤并让模型停手

**Status:** ready-for-agent

见[第三阶段规格](../spec.md)。先用按比例点击验证完整循环。每轮只处理一个决定。停手不计步，每次实际发出的动作计一步，上限用载入值。最后一个动作成功且用完上限时直接结束，不再请求模型。

发送动作前验证结构和参数。实际发出的动作按顺序保留短说明原文和动作后截图。动作失败时保留当轮已经取得的轨迹字段。此前轨迹在后续模型、动作或截图出错时仍保留。用例执行入口返回这些信息，便于后续报告读取。

- [ ] 模型请求按比例点击时，设备替身收到按现有规则计算的像素坐标
- [ ] 第二次模型请求含第一次动作后的新界面，按顺序发生
- [ ] 上限为 1 时，只发出一个动作和一次模型请求；达到上限或模型停手时步骤为已执行
- [ ] 每个已发出的动作有一条轨迹，保留动作参数、短说明原文和动作后截图。停手不增加轨迹
- [ ] 非法比例、未知结构、单轮多个决定、携带当前密钥的可记录字段在派发前拒绝
- [ ] 中途模型失败、动作失败或截图失败时步骤为错误，已取得的轨迹保留，后续动作与步骤不执行
- [ ] AI 步骤返回结束截图，已用完上限时可复用最后一次动作后的截图
