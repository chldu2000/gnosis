# 03 让模型使用全部现有动作

**What to build:** 模型可以用普通步骤已有的动作完成目标。相同动作和参数经过同一套定位、换算和设备操作规则。

**Blocked by:** 02 执行模型动作并记录轨迹

**Status:** ready-for-agent

见[第三阶段规格](../spec.md)。在按比例点击基础上补齐启动应用、定位点击、长按、滑动、输入文本、按键和等待。对每种模型动作验证参数名称、类型和必填性，再交给普通动作所用的执行逻辑。遵循已有动作的时长默认值、定位器规则和设备错误语义。

输入只替换当前焦点里的文本。等待只推进时钟，仍计入步数上限，并保留结束截图。界面文字可帮助模型识别目标。允许的动作取决于执行器的固定集合。

- [ ] 测试通过同一个执行入口覆盖所有允许的模型动作，并与普通动作的设备参数或时钟变化比较
- [ ] 模型启动应用支持省略或指定入口，按键只支持返回和主页
- [ ] 定位点击和长按沿用原有匹配、索引和屏幕文字后备规则
- [ ] 模型的比例和时长遵循原有范围、换算规则与默认值
- [ ] 输入替换当前焦点，等待消耗给定时长并计一步
- [ ] 任意命令、未知动作、无效键名、缺失参数、额外参数或错误类型都会拒绝，设备没有收到该动作
