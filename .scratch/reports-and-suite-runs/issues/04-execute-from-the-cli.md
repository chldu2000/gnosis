# 04 从命令行执行用例或套件

**What to build:** 命令行使用者提交一份用例或套件文件并显式选定设备，可以取得已保存报告的路径以及供流水线使用的退出码。

**Blocked by:** 02 在报告中呈现 AI 轨迹与输入法注明；03 在同一台设备上执行套件

**Status:** resolved

见[第四阶段规格](../spec.md)。命令行先校验入参并完整载入，然后打开选定设备并调用共用执行入口。普通用例无需模型信息。AI 步骤可使用宿主的模型设置，本次执行允许覆盖模型选择。用例或套件已保存的报告按顺序在标准输出逐行列出，诊断写到标准错误。

- [x] 显式设备标识可选中指定设备，缺少设备标识或载入失败时不会执行
- [x] 一个入口接受用例或套件，套件的每份已保存报告按执行顺序逐行打印
- [x] 通过、已执行以及只含这两种结果的完整套件返回零
- [x] 失败、阻塞、错误、设备不可用、参数或载入错误、未能完成套件以及报告保存失败返回非零
- [x] 套件失败或阻塞后继续收集报告，命令最终仍返回非零
- [x] 保存失败时只打印已经保存的报告路径。诊断在标准错误，模型密钥与认证头不出现在输出中
- [x] AI 使用宿主设置或本次模型覆盖值，普通用例无需模型设置；标准输出保持为报告路径

## Comments

使用设备替身和本地模型服务验证参数、标准输出、标准错误及退出码。Windows 构建通过，已运行 `--help` 和缺少参数的命令。见[命令行测试](../../../cmd/gnosis/main_test.go)和[使用说明](../../../docs/cli-execution.md)。
