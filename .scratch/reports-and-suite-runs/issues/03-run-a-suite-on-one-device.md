# 03 在同一台设备上执行套件

**What to build:** 载入完成的套件可以在一台设备上按顺序执行。每条已开始的用例独立保留结果和报告路径。失败或阻塞后继续，遇到执行错误后停止。

**Blocked by:** 01 保存一份用例执行报告

**Status:** ready-for-agent

见[第四阶段规格](../spec.md)。套件执行从第一条用例开始前取得进程与设备占用，直到套件结束才释放。复用已有的单用例执行逻辑，每条用例独立记录开始时间和结果，并在确定结果后按需恢复输入法。套件只汇集按序返回的用例执行记录、报告路径和可能的故障。

- [ ] 按套件引用顺序执行，重复引用得到独立的执行与报告
- [ ] 竞争执行在整个套件期间被拒绝，结束后设备可重新取得
- [ ] 失败或阻塞后，下一条用例仍开始；执行错误后，后续用例不开始
- [ ] 设备在两条用例之间变为不可用时及时停止，未开始用例没有结果或报告
- [ ] 每条用例的输入法恢复在下一条开始前完成尝试，恢复失败只增加注明
- [ ] 报告保存失败保留已得到的用例结果和先前报告，停止后续用例并释放设备
- [ ] 空套件、无法完整载入的套件、开始前离线或占用冲突都不会执行第一条用例或留下报告
