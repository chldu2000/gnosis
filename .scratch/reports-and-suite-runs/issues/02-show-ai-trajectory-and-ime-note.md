# 02 在报告中呈现 AI 轨迹与输入法注明

**What to build:** 测试编写者能从同一份报告查看 AI 步骤及它已经发出的各轮动作，以及输入法恢复失败的注明。

**Blocked by:** 01 保存一份用例执行报告

**Status:** resolved

见[第四阶段规格](../spec.md)。使用执行记录里的轨迹。每轮按顺序呈现动作和参数、模型短说明原文和该轮结束截图。AI 步骤本身也有独立结束截图；动作或截图失败时保留此前与当轮已取得的信息。报告显示输入法恢复注明，并沿用已确定的用例结果。

- [x] AI 步骤结束截图与各轮截图均可从同一份报告查看
- [x] 轨迹按动作顺序显示，短说明保留原文，缺图有明确标记
- [x] 停手且没有动作时轨迹为空，中途出错时已有轨迹仍出现在报告
- [x] 输入法恢复失败的注明可见，用例结果保持原样
- [x] 用例、动作参数、诊断和模型说明按普通文本呈现；宿主密钥、认证头、完整模型请求和原始响应没有进入报告

## Comments

通过 `Run` 和本地模型服务验证轨迹、步骤结束截图、文本转义和密钥脱敏，并覆盖停手、部分轨迹、缺图和输入法恢复失败。见[报告测试](../../../report_test.go)。
