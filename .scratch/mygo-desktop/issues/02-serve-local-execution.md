# 02 独立的本机执行进程

**Blocked by:** 01

**Status:** resolved

- [x] 每个 Windows 用户连接自己的执行进程。命名管道仅接受授权的本机用户，进程提供设备列表、启动、查询、订阅和控制。
- [x] 断线可以按请求 ID 查询启动是否接受，并从最新状态和事件序号接续进度。
- [x] 进程保留最近一次执行、已确定结果和报告链接。确认异常退出后恢复为「执行中断」。没有窗口连接且进程空闲时在保存状态后退出。

## Comments

进程测试覆盖按请求 ID 查询、重复启动、断开订阅和异常退出快照。Windows 桌面验收确认关窗时运行进程仍持有设备，终态落盘后进程可退出，新进程可恢复最近一次记录。见[执行进程测试](../../../internal/localrun/manager_test.go)。
