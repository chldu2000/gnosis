# 05 原生桌面工作台

Status: resolved

采用原型 A。左栏管理当前窗口的文件，中间显示步骤列表和字段详情，右栏始终显示执行。缩窄窗口时把文件列表收进「用例与套件」。

「准备执行」和「准备新执行」显示在右栏顶部。当前执行、上次同步的快照、待核对的请求和已保存的报告按状态显示。定位步骤需要匹配执行进程实际载入的用例文件及其版本。

已确认的 HTML 原型归档于本地分支 `prototype/desktop-workbench` 的提交 `383d908`，文件路径为 `cmd/gnosis-desktop/desktop-shell-prototype.html`。

## 验收

- MyGo 在 1040×740 和 760×540 渲染工作台。交互测试验证右栏启动区排序、设备离线后手动切换、核对启动、保留文件草稿和输入焦点，以及匹配文件版本后定位步骤。
- Windows 命名管道连接 Android 真机，执行含重复引用的三条用例。第二条暂停后断开再连接，核对请求获得相同执行 ID，继续后取消。核对了第一条和第二条报告中的真机截图，第三条保持未开始。
